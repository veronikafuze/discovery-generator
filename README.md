Discovery Generator 🧠🔬
Инструмент на Python для поиска неочевидных связей между научными статьями и генерации исследовательских гипотез с помощью ИИ.

Что делает проект:
Скачивает свежие статьи из двух разных наук.

Находит пары статей, которые говорят об одном и том же, но на разных языках.

Отправляет эти пары нейросети (ИИ), чтобы она придумала гипотезу.

Сохраняет красивый отчет в файл output/hypotheses_report.md.

Инструкция по установке:
Скачайте код и откройте терминал в папке с проектом.

Установите зависимости командой: pip install -r requirements.txt

Скачайте программу Ollama (ollama.com) и модель командой: ollama run llama3.2

Запустите скрипты по очереди:

python 1_fetch_papers.py

python 2_embed_and_find_pairs.py

python 3_generate_hypotheses.py

Как поменять научные темы:
Откройте файл config.py и найдите строки:
CATEGORY_A = "q-bio.NC"
CATEGORY_B = "cs.LG"

Вместо них можно вписать любые другие категории с arXiv.
Примеры для экспериментов:

cs.CL (Лингвистика) + econ.GN (Экономика)

q-bio.QM (Биология) + physics.chem-ph (Химия)

cond-mat.mtrl-sci (Материалы) + cs.AI (Искусственный интеллект)

Если ноутбук слабый (используем облачные ИИ):
В файле config.py измените настройки:
LLM_BACKEND = "groq"
GROQ_API_KEY = "ВАШ_КЛЮЧ"
Ключ можно бесплатно получить на сайте console.groq.com

Результат
После запуска откройте папку output и файл hypotheses_report.md. Там будут все сгенерированные гипотезы со ссылками на статьи.

Проект создан для ускорения научных исследований.
